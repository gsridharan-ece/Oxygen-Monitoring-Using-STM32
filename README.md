# Oxygen Monitoring Using STM32

A bare-metal embedded project built on the **STM32F401RE** microcontroller. It reads oxygen concentration from a UART-based sensor and shows the result on a 16x2 I²C LCD and a PC serial terminal.

**Notice:** This project is shared for viewing and reference only. It is not a certified medical device and must not be used for patient monitoring, diagnosis, or any clinical purpose. All rights reserved. No permission is granted to copy, modify, distribute, or use this code.

---

## Features

- Reads oxygen concentration from a UART sensor
- Displays the reading on a 16x2 character LCD over I²C
- Streams readings to a PC serial terminal
- Reports a "No Response" message if the sensor does not reply
- Uses timeouts on blocking peripheral operations

---

## Hardware

- **Microcontroller:** STM32F401RETx (Cortex-M4), e.g. NUCLEO-F401RE
- **Sensor:** UART oxygen sensor
- **Display:** 16x2 LCD with I²C backpack
- **PC link:** UART to serial terminal (ST-LINK virtual COM port on Nucleo boards)

---

## Software

- Language: C
- IDE: STM32CubeIDE
- Approach: bare-metal, register-level programming with CMSIS
- Peripherals used: UART, I²C, ADC, SysTick

## Build

Requires [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html).

1. Import the `o2level_1` folder using **File → Import → Existing Projects into Workspace**.
2. Build with **Project → Build Project**.
